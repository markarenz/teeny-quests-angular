Teeny Quests' Quest Editor

What is Teeny Quests? Wait. Should it be what ARE Teeny Quests? Regardless of grammar, Teeny Quests is a browser-based isometric adventure/puzzle game. More than that, it's an application for people to make tiny games of their own: quests that other people can play.

We're not going to go into what's going on under the hood in this video. That's for another time, but the impetus of a project like this is obvious: goofing around in a level editor is about the most fun any human person is allowed to have. If you've ever so much as dipped your metaphorical toe into making Doom levels, you know what I mean.

Creating your own quest in Teeny Quests couldn't be simpler. First, create an account and log in. You can't pick your own username. This is intended to help prevent people from using their usernames and other free text input to harass other players or for other generalized antisocial behavior. So, if you want to set your own username, please do what you can to make the Internet a less terrible place. Once you've logged in, go to the menu and select Quest Editor. From there you can click on the New Quest button to get started. Give your quest a name and a description for the game selection screen. You can always change this later.

A relatively simple set of objects and rules can create something the original devs may not have imagined. That's where you come in. Ready? Let's go!

A quest is made up of separate components that come together to form the level. We have areas or rooms that the player travels through, and in these areas we can have exits to travel between areas (or just within an area), items as well as props.

Map Cells are the floors and walls of a given area laid out in a small grid. You can use the map cells to create towers, castles or natural landscapes with specific textures and varying heights.

Items can be picked up and carried around and can be used in the right circumstances. For example, some items like keys can only be used in the presence of a door that can be opened with that type of key.

Props cannot be picked up and used, but they can be interacted with like a switch or banner on the wall. Props have states like on or off, and you can attach actions to each status.

Flags are like variables in the game state that you define. For example, if the player flips a switch you can set a flag to true or false that could be used in combination with other flags.

We also have Events, which are actions attached to a set of conditions. We run the events check on every player action, so you can create an event that looks at your inventory for a specific amount of gold and sets a flag or does some other action like ending the quest.

Let's dig into what each of these mean in detail.

1. Areas

Every new map starts with an area called "start" but you can set the start to another area if you want. Just set it in the quest info panel. This is where you set the player start position, define flags and set the initial inventory.

Create a new area with the + button and give it a name. Switch between areas with the dropdown.

2. Map Cells

The view is isometric, which can be a lot of fun to work in, but be careful not to leave too many blind spots. Since the player can click on an available space and travel into and out of a blind spot, it's not usually a problem, but you should be aware of it.

To change a map cell, just click on it or use the position selector to pick a map cell. Sometimes a map cell may be hard to select due to the height of surrounding cells, so just use the position selector in that case.

Set the height up or down. Max is 24, min is 0. Players cannot walk on cells of height 0.

Set the floor type. Some floors are not walkable such as spikes or a roof.

Set the wall types. You can select different left and right walls if you want as transitions from one part of the area to another.

You can also hide a map cell for making interesting non-square areas. You can unhide it easily by using the position selector and clicking Unhide.

We can also select multiple map cells at once for bulk editing, setting the height, floor and wall types at once. This can be very handy, but you'll want to switch back if you don't need it.

With multi-select on, you can also select cells by shape such as All, ring 7, ring 5 center 5 and center 3. Speaking from experience, this saves a load of time and makes editing quests more enjoyable. Why I waited to implement this until I had nearly 8 quests completed is beyond me, but enjoy.

3. Exits

We would naturally think of exits as tools for connecting areas but in reality exits connect to other exits. Each normal exit has fields for destination area and destination exit. Note the checkbox for reciprocal exits. With it on, connecting door A to door B will also connect door B back to door A. Very convenient. This is optional, of course. Disable it if you feel like making quests with illogical doors to drive players insane.

Select a direction and a position for your door.

You can lock the door with either a silver or gold lock, which can only be opened with a key of the corresponding color. The player stands in the same map cell as the door and selects "use" (the hand button) in the inventory menu to unlock the door with a satisfying sound effect.

The default type of door is the one you'll use most often along with a "cave door" for exits in ruins or dirt walls.

An exit of type "quest end" will, as the name implies, end the quest and is used for a "find the exit" type of quest. We'll use one of these in our example later.

The quest end door isn't the only way to end a level. It's important to remember that you can create all sorts of quest goals and even have multiple ways to end a quest.

4. Flags

Flags are kind of like variables in the game state that let us keep track of what the player has already done. We use this for one-way actions, which we'll talk about in a bit.

Flags have scores associated with them, so you can use this to reward players for progress. -

You can use actions from props or events to set flags or check progress on a series of flags and set another flag when complete. This is how you can chain quest goals together to create complex compound quest objectives.

5. Items

Items are objects that can be picked up, dropped and used in the course of the quest. This includes gold, keys, and gems. More items may be added later.

Each item also has a score value associated with it, so you can place a bunch of high value items like gold bags or rubies around to give players loot to collect for higher scores.

Keys can be used to unlock doors if the player is standing on the same map cell as a door with a lock of the same color.

Gems like diamonds and rubies are loot that boost your score when you collect them. They can also be used in gem frame props, which will trigger actions - more about that later.

6. Props

Props are objects the player can interact with but not pick up or move such as torches and switches.

Naming props can make it easier to create actions to change their state. You can have several actions on each state.

These actions are a big part of making an interesting and creative quest for players. Currently, you have a limited palette of actions since frankly you can do a lot with just a few actions, but there are plans to add more over time.

For example, you can add a switch prop with actions for the on and off status. So you can turn on or off a torch in the room like a light switch by selecting an action type that changes a prop's state. We select the torch and set it to on. This is where naming the props can be handy.

We can also change the height of a map cell. This is helpful for fencing off items or pathways through your quest. I like to give movable map cells a specific floor type, but you can do what you want. For on, we set the height to one level and for off, we set it to another level.

We can also change the floor type in an action. This is helpful for making a secret bridge pop out of the water by combining it with an action to change a map cell's height.

When you select the map cell, if it's in the same area, you'll see an indicator telling you which one you're selecting. This is meant to help make this process easier.

A fun example of what you can do with props is a simple elevator. Put up a tall column with a switch prop on it with a solid walkable tile below and next to it. The switch status actions for 'on' can change the height of the map cell the prop is on to make it higher, then 'off' can return it to the original height. In no time flat, you've got an elevator!

Gem frames are another prop. These are basically shapes in the wall where you can, for example, "use" a diamond to put it in the frame. This can then trigger actions.

Since using up an item removes its score value, you will want to trigger a flag with a high score value to compensate. Otherwise the score drops when the player does what you want them to do to progress. Or maybe you want that to happen, which is fine as well.

7. Events

Events work just like props but instead of clicking on them to trigger actions, we use conditions that are checked after each player action. Your conditions could be related to inventory or a feature flag. We may add more condition types later, but there's a lot you can do with what we already have.

This allows you to set multiple endings for your quest. For example, you can create an event to check the amount of gold in your inventory and if it's over 1000, the quest is complete. You can also have an exit door, so the quest could be completed in multiple ways. Just add an action to set game end flag to true.

When you set a name for an event with an action that sets game end flag, this text will be used in the opening statement of quest goals when the player starts the quest. So, try to use a name that will make sense like "Collect 1,000 gold coins" or "Put all the gems in their frames."

For example, you can use an item as your McGuffin. If the player picks it up, the quest is complete.

Events can be unidirectional, meaning that the player can only do it once. We do this by creating a special flag for the event, and if it's unidirectional we set the flag so the event cannot run again. This all happens under the hood, so you just check the box and don't need to worry about it.

8. Actors

Actors are interactive entities that can move about, or at least some of them can. It's a catch-all entity type for hostiles or shops. So, this introduces two new mechanics to the game: combat and an economy. We'll cover each separately.

8a. Hostiles

There are a handful of enemies in the game that you can mix and match in your quests, each one a bit nastier than the last. The biggest and baddest of these is the Skello King, who can easily pound an unprotected player into the ground in a couple of turns.

Stand next to an enemy and click on them to attack. If the player hasn't grabbed a weapon yet, they'll be fighting with their bare hands, a low chance to hit and low damage. You won't get very far that way.

As a quest editor, you may want to place a low level weapon like Pointy Stick early on in the quest then upgrade to the Adequate Blade or, if you want them to go full OP, the Sword of Awesomeness. You can also place defensive items like the Ring of Protection.

There is no equipping mechanic (on purpose to keep things simple) so the best weapon will always be used. You can see it in the messages that pop up on the right side of the screen. Defense buffs are additive, so if you give the player more than 1 ring of protection and they have both, the defense buff is additive. You can make the player an unstoppable death merchant or a fragile weakling. It's all up to you and the player's willingness to search for goodies.

When defeated, each hostile can drop an item. You can set this easily in the editor so you can drop a key needed to progress from one of the enemies. You can also trigger actions like you can for events and props just like Doom. You can choose to ignore combat entirely if you want or use it as a gating mechanic for progression. It's up to you.

8b. Shopping!

Shops in the game are very simple. Just create an actor in an area, place it and set the type to Shop. Then select which items are available for sale.

This also sets the items that the shop will buy from the player, which allows you to determine difficulty. Sometimes shops can be used to short-circuit a play path, so you may want to not allow the purchase of keys in the shop. Or, as I did in Tell Your Mom I Said Hello (OK, I ran out of ideas for quest titles) I didn't place a silver key at all, which is needed to get the first weapon. Instead, I made it available in the shop and placed gold around so the player can figure it out and play it safe if they choose or rush through and fight with their bare hands and put their fate in the hands of the RNG gods.

Misc

If your logged-in session expires before you had a chance to save, no worries. Log in on the same browser and click Restore from Local, then save your changes. We save to your browser's local storage when you change your quest as a backup.

Test your games as you go using the Play button. You can set the player start area to shortcut the process to make testing longer quests easier.
